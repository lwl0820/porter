# A 浅色蓝白双后台实现与浏览器复核

## 目标与用户价值
将用户选定的 A 浅色蓝白方案实现到 Porter 管理端和用户端，用户管理采用已确认的紧凑表格列表；使用内置浏览器逐页对照设计稿迭代，使布局、层级、配色、间距、字体和密度尽量一致，同时保留现有业务能力。

## 已确认事实与决策
- 用户最初要求创建任务、用生图工具设计双后台每个页面并提供多种风格；三套方案、六张全页面设计板和三张列表版用户管理单页已经生成并交付。
- 用户明确要求用户展示使用列表，避免用户较多时卡片杂乱；随后明确选择 A，并要求实现及通过内置浏览器对比复核。
- 管理端包含登录、转发规则、套餐管理、用户管理、系统配置五页；用户端包含登录、转发规则、账户概览三页。两端规则创建/编辑及现有确认弹窗同时纳入改造。
- 前端为 Vue 3 / TypeScript / Vite；共用 App.vue 和 style.css，角色与 API 前缀独立。AdminResources.vue 负责套餐、用户及端口池；AccountOverview.vue 目前同时用于用户本人及管理员下用户卡片。
- 本轮采用原生组件与现有依赖；不引入 UI 组件库。三张 A 参考图是视觉依据，现有接口契约是功能与数据依据。

## 范围与需求
- R1：管理端以 design-options/a-admin.png 为视觉基准，用户端以 a-user.png 为基准；用户管理以 a-users-list-v2.png 优先覆盖旧管理端设计板第4格。B/C 仅保留历史备选，不实现主题切换。
- R2：实现全部八页及两端规则编辑；统一蓝色 Porter 标识、白色页头、横向导航、蓝色选中下划线、冷白底色、细边框、轻阴影及圆角。
- R3：用户管理使用全宽语义化表格，一行一个用户。列为用户名、套餐、分配端口、计费用量/额度、上行/下行、计费方式、重置方式、下次重置（UTC）；窄屏保留可横向滚动的列表。添加用户入口位于页标题右侧，通过现有原生弹窗承载创建表单，使列表成为主体。
- R4：登录采用浅蓝背景、蓝色网络几何装饰与白色表单卡；规则页使用紧凑统计卡、筛选工具栏、明确的地址和协议、上下行累计及速度、状态与操作；套餐页先展示套餐卡再展示创建表单；配置页为集中端口池表单；用户规则页为紧凑套餐摘要，账户页为完整套餐、用量进度与周期信息。
- R5：规则编辑在桌面使用居中弹窗，明确源地址到目标地址的关系；保留三协议选择、归属锁定/选择、分配范围、统计和启用两个开关及准确的会话中断提示。窄屏表单可滚动，操作可达。
- R6：沿用独立鉴权、CSRF、revision、异步版本保护、5秒轮询、精准流量、四种计费与三种周期；数据和状态真实，不照抄生图错误日期、数值、计费文字或不存在的功能。
- R7：保留中文/English、键盘操作、焦点恢复、可访问名称、加载/空/失败/额度用尽等状态。页面中不展示设计任务、验收步骤或开发说明。
- R8：使用内置浏览器查看实际运行的页面，对照三张 A 基准图逐页截图、记录差异并迭代；检查桌面和390px窄屏、中英文、至少14行用户及关键弹窗。最终交付截图和差异记录。

## 验收标准
- [x] AC1：八个页面及规则编辑均采用 A 的统一视觉语言；登录、套餐、配置与账户分区符合对应基准图，覆盖 R1、R2、R4、R5。
- [x] AC2：用户管理至少14行示例时为列对齐的紧凑表格，八个字段列齐全，不使用用户卡片；添加用户可从标题按钮完成，创建成功刷新列表，覆盖 R3。
- [x] AC3：规则创建、编辑、筛选、启停、删除、重试、流量重置和套餐/用户创建及端口池保存仍可用；权限、统计、版本冲突和会话过期行为不回退，覆盖 R6。
- [x] AC4：账户进度按权威用量计算且不丢失大整数字节精度；四种计费、三种周期、UTC时间、额度耗尽、缺少套餐等情况真实显示，覆盖 R4、R6。
- [x] AC5：中英文和390px页面无操作遮挡；用户管理窄屏横向滚动；弹窗焦点、取消、提交禁用与返回可用，覆盖 R3、R5、R7。
- [x] AC6：前端 lint、type-check、test、build 均通过；最终产物通过 Go 嵌入及相关测试，覆盖 R6、R7。
- [x] AC7：内置浏览器实际打开双端八页及编辑视图，保存截图与逐页差异记录，对明显结构差异完成修正；没有把仅构建或测试通过称为视觉复核完成，覆盖 R8。

## 范围外
不修改后端 API、数据库、权限或计费规则，不新增支付、注册、找回密码、套餐/用户删除编辑、批量操作、搜索排序或后端分页，不部署远端。浏览器样例使用本地隔离数据；不使用真实生产用户数据。

## 风险与限制
生图为多页面拼板，页面尺寸与文字不具有像素级合同效力；按相对布局和视觉语言还原，正常字体与真实数据优先。登录几何装饰采用本地 CSS/SVG 实现，以可缩放并保留文字清晰。宽表在空间不足时局部横向滚动。任何必要偏差均记录在最终浏览器复核文档。
