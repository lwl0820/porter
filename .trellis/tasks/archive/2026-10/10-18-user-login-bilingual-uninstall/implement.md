## 执行顺序

1. 主会话加载实施阶段指引，派发 `trellis-implement`，提示以当前任务路径开头。执行者读取本任务需求、设计、计划与清单；共享工作区，禁止覆盖其他已有改动。
2. 实施者先完成集中消息和语言参数/选择，保留默认安装语义、控制终端与隐藏密码；用中英文帮助及现有安装测试及时验证重构行为未回退。
3. 实施卸载状态、归属校验、确认、停服、文件删除、默认保留与彻底删除；同步实现卸载后同版本重装及中断恢复。
4. 扩展命令替身和伪终端行为测试，验证取消不修改、失败次序、保留与删除清单、额外文件、自定义路径、重复执行、锁与恢复。
5. 修改生产和开发根入口、安装输出和中英文 README，补齐根地址和双端回归。
6. 派发 `trellis-check`，以全量最终差异为范围，核对规格、跨层行为与测试，修复发现的问题。
7. 主会话复核验收与实际浏览器结果，更新前后端实际契约和本任务验收记录，按项目提交与收尾流程处理。

本任务规模有限，采用同一实施者顺序修改入口和脚本，避免多执行者同时修改 `install.sh`、测试或 README。检查由独立检查者完成。

## 验证命令

缓存、构建与测试临时目录统一放入仓库 `.tmp/`；执行前设置相应 TMPDIR、Go 缓存与 npm 缓存，禁止使用系统临时目录。

```bash
bash -n scripts/install.sh
bash scripts/install.sh --help --lang zh-CN
bash scripts/install.sh --help --lang en
python3 scripts/test-install.py
npm --prefix web run lint
npm --prefix web run type-check
npm --prefix web run test
npm --prefix web run build
go vet ./...
go test -race ./...
git diff --check
```

先完成前端构建，再运行 Go 嵌入相关检查，不能与清空 dist 的构建并发。若修改工作流另执行 actionlint；工作流不变则不扩大验证范围。

## 必验行为

- 根地址 GET/HEAD 到用户端；显式管理员和用户端及其深链接正常，未知 API 和资源保持 404。
- 开发根页触发用户端会话接口，未登录显示普通用户登录；生产构建通过 HTTP 确认同样结果。
- 中英文帮助、首次语言选择、默认中文、非法参数、安装重试、卸载确认与结果；密码不出现在输出和命令日志。
- 默认卸载停服、禁用自启、删除托管程序和 unit；环境配置和完整数据内容不变，账号与受限状态保留。
- 默认卸载后重装同版本，复用原始凭据、监听地址和数据库；原本 complete 状态缺失数据库仍拒绝，防止新状态削弱原有保护。
- 彻底删除需两次明确确认；取消与无终端时不修改；成功清理托管账号/组、配置及数据，保留安装目录中的额外文件。
- 自定义目录自动识别与显式不匹配拒绝；未知服务、路径链接、非法记录和其他进程锁均不删除。
- 停服、禁用、删除或 daemon-reload 失败返回非零，保留恢复信息；中断后重试及重复卸载可解释且不误删。
- 卸载过程中没有 GitHub、curl、包管理安装或凭据采集；安装器原有发行版、架构、下载校验和故障恢复回归继续通过。

## 回退与风险

- 保留全部已有未跟踪的 Trellis/平台初始化文件，只处理本任务差异，不执行整体重置或清理。
- 语言重构和状态扩展是主要回归点，必须在最后一次修改后运行完整安装器行为测试。
- `uninstalled` 记录依赖新版脚本，老脚本不可直接用于重装；保留数据重装仍依赖记录版本的 Release 可下载。
- 彻底卸载不可依靠代码回退恢复数据，本轮开发只用模拟目录验证，绝不对实际宿主运行卸载。
- 最初规划不包含推送、标签与服务器操作；用户在最终提交确认时追加授权：提交后合并主分支、删除开发分支并推送。不创建标签、不操作实际服务器。
