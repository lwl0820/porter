# 双语产品文档实施记录

## 本轮修改

仅修改 README.md、README.zh-CN.md 及本记录，未改产品代码、规范或 Git 状态。

- 首次安装语言后分别选择 Web 与命令行，默认双开、至少一种；用表格区分三种入口和 Web 输入要求。
- 仅命令行无需 Web 凭据和监听地址；仅 Web 不安装托管客户端、PATH 入口及本机控制 socket；后台转发服务始终运行。
- 重跑脚本默认保持现组合，可显式相互切换，说明重启影响、保留业务数据及语言、复用合法 Web 配置、同版本补装 CLI 和失败/中断恢复。
- 旧单程序先显式升级保留 Web，旧双程序保留双入口，再重跑切换；卸载重装保留原组合，升级及切换备份/purge 边界保持。
- 增加组件环境变量及 Web 条件校验；说明托管安装通过脚本切换，避免手改配置与状态不一致。
- CLI 内容按是否启用限定，说明无 Web 时现有用户规则/配额继续生效，用户及套餐管理仍需 Web。
- Docker 保持仅 Web；手动运行说明 --check-config 无数据库及监听副作用，不能代替端口就绪检查。

## 冻结源码核对

已收到 feature_installer 的交互定稿说明，并实际阅读 scripts/install.sh 的 features/programs、配置生成与预检、三模式就绪、collect_input/select_features、run_upgrade/run_reconfigure、恢复/备份、卸载和主流程。

核对结果：

- 首次两项默认 yes，全关重选；已有安装询问是否修改管理组件，默认 no，显式 yes 后按当前组件作为默认值，最终确认再执行切换。
- schema1 显式升级保留仅 Web，schema2 保留双入口；旧程序能力预检失败在停服前拒绝。
- 不变选择不重启、不升级，保留原 active/enabled 意图；文档已把新装 active/enabled 成功条件限定为首次安装，避免与停止实例重跑矛盾。
- 首次开启 Web 且旧配置无效才收集用户名、隐藏密码/确认及地址；合法配置复用。关闭 Web 保存旧配置，关闭 CLI 保留偏好。
- 同版本补装客户端；服务端始终部署，Web-only 不部署客户端或托管入口。
- 备份目录沿用 .tmp/upgrade.<标识>，回滚失败候选数据沿用 .porter-failed-upgrade.<标识>，purge 保留历史副本并提示风险。
- 新增简短产品说明：开启 Web 与已有启用 TCP/组合规则监听冲突时拒绝切换并保留原组合/规则，先调整 Web 地址或规则再重试。不暴露内部数据库预检实现。
- CLI-only 没有 HTTP 健康端点；就绪使用 root 只读控制查询，不触发语言保存。Docker 仍仅 Web。

未发现与冻结安装器不一致的产品表述。没有运行安装器测试或真实 systemd 宿主验证；实际模式/网络/恢复验收由主会话与独立检查完成，文档静态检查不代替这些测试。
