3. 服务协调：恢复累计量、单个采样循环、周期批量落盘、脏标记重试；串行化重置与删除；Close 幂等、等待会话和最终刷新，main 报告退出保存错误。

## 必要行为验证

- 存储：空库、v1、v2 升级与重开，默认关闭、旧字段无损、迁移失败回滚、累计量与开关恢复、删除清理、失败不丢待写累计值。
- 转发：真实 TCP/UDP 上下行字节与组合聚合；长连接尚未结束即增长；部分写入、失败和丢包不超计；半关闭与会话预算回归。
- 生命周期：仅切换统计或重置不主动断连，关闭期间不计数，重开继续；正常退出最终落盘、双 Close 不死锁，监听重建和重试不清空累计值。
- 并发：固定/可控时钟验证速度，空闲归零、多个读者互不影响、重置后无旧增量/负速度、周期快照不能覆盖重置或复活删除记录；开启竞态检查。
- API：默认与省略字段行为、拒绝非法统计字段、同 revision 并发修改/重置仅一方成功、鉴权/CSRF/Origin 拒绝、重置失败保留状态。
- 前端：新增默认关闭、编辑回显与保存、上下行单位和大整数格式、关闭显示、重置取消/成功/失败/412、防重复、旧轮询不覆盖重置，图标无障碍名称。
- 浏览器：实际桌面与窄屏展示，编辑开关、统计刷新、重置确认和连续转发；临时日志、截图和测试数据均放仓库 .tmp。

## 验证命令

工具缓存和临时目录先配置到仓库 `.tmp/`，不使用系统临时目录；Go 测试临时目录遵循 internal/testutil.TempDir。

1. `npm --prefix web run lint`
2. `npm --prefix web run type-check`
3. `npm --prefix web run test`
4. `npm --prefix web run build`
5. 前端构建完成后 `go vet ./...`、`go test -race ./...`。
6. `CGO_ENABLED=0 go build ./cmd/porter`，产物定向放 `.tmp/`；必要时复用 scripts/docker-smoke.py 验证容器升级与统计恢复。验证脚本临时目录必须显式位于仓库。
