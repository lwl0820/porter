## PATH 位置选择

最初考虑 /usr/local/bin/porter，但目标发行版包含 RHEL 9/10，需要兼容 sudo 的受限 PATH。Red Hat 官方文档示例的 secure_path 为 /sbin:/bin:/usr/sbin:/usr/bin，不含 /usr/local/bin。因此拟定固定 /usr/bin/porter，目标指向实际安装目录的 porter，避免修改 sudoers 或用户 profile。

官方依据：https://docs.redhat.com/en/documentation/red_hat_enterprise_linux/9/html-single/using_ansible_to_install_and_manage_identity_management/index ，以及 https://docs.redhat.com/en/documentation/red_hat_enterprise_linux/10/html/managing_idm_users_groups_hosts_and_access_control_rules/granting-sudo-access-to-an-idm-user-on-an-idm-client 。该选择是基于官方示例和本项目兼容目标的工程判断，不宣称全部用户自定义 PATH 一定包含该目录。
