- Dockerfile 只编译 `cmd/porterd`，保持 `porter_docker` 标签；最终只复制 `/porterd`，ENTRYPOINT 同步切换。
- `scripts/build-release.sh` 每架构使用新建且受控的 `.tmp/package-ARCH.XXXXXXXX` 暂存目录，构建同一 VERSION 的两个无 CGO 程序；归档精确包含 porter、porterd、README.md、README.zh-CN.md 四个普通成员，归档命名和 SHA256SUMS 保持。

- 容器 smoke 验证 `/porterd` 入口、拒绝规则参数、没有 `/porter` 或 `/usr/bin/porter` 及默认/自定义控制 socket；保留全部业务断言。
- 双语 README 更新两个程序的责任、PATH、首次保存语言、显式语言覆盖、卸载/purge、显式升级和手工 unit/Docker 入口迁移。
