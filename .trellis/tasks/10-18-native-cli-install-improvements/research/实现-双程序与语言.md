# 双程序与语言配置实施证据

## 范围与实现

本组仅修改 Go 源码及 Go 测试；未修改安装器、发行脚本、Dockerfile、README、工作流或规范，未提交 Git。

- cmd/porter 仅为客户端；裸命令进入规则菜单，保留 porter rules 参数入口，--version/-version 在任何语言与文件访问前返回。
- cmd/porterd 承接原有服务生命周期；独立参数解析在日志、管理员配置与数据库前完成，非法 rules 写标准错误并退出2；版本独立。
- internal/controlapi 承载共用协议、错误与客户端；internal/localapi 仅为服务，原有真实对端与套接字安全逻辑不变。真实 Linux 文件限定 !porter_docker；Docker采用server_other.go空实现。
- CLI配置固定 /etc/porter/cli.json，schema=1、language=en/zh-CN。无显式语言时先读取合法保存值，否则终端1English/2中文、回车英文；确认后保存，q/EOF/中断不保存。--lang只本次覆盖，菜单6切换并保存。
- 帮助、非root和容器调用不保存系统设置；版本不触碰配置。无TTY无偏好报英文language_required；损坏配置明确报preference_invalid并允许显式--lang绕过本次读取。
- 保存失败警告但继续本次选择；提示写stderr或控制终端，不混入JSON stdout。首次并发保存采用第一个已确认的合法保存值，避免互相覆盖。

## 配置安全与安装器协调

- 路径通过root可信目录描述符逐级openat+O_NOFOLLOW访问；拒绝非root属主、group/other可写目录、链接、非普通文件、额外硬链接、非0600模式、超大文件、非法schema/语言/未知或重复键。
- 受限同目录.cli-<24hex>.new文件，明确chmod0600以不受限制性umask影响；写入与fsync后原子rename，再fsync目录。
- 不持锁等待用户输入。仅保存阶段mkdir /etc/porter/.install-lock，短时等待，不删除其他进程的锁；释放时校验本次锁的inode。
- 读取时记住已有配置目录inode及install.json精确字节；保存在安装锁内重校，拒绝已消失/替换目录和变化的记录。状态仅允许缺record或schema1/2的initializing/complete；uninstalling、uninstalled、升级中等状态拒绝保存。
- 原存在后被卸载的配置目录不能被重新创建；读取时本就不存在的首次配置目录可由原生root创建。
- 安装器代理已收到锁、状态、文件模式及临时文件名合同，purge负责精确清理cli.json和可验证的未提交文件。
