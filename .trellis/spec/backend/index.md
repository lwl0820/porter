# 后端开发规范

覆盖环境变量、认证、规则服务、转发引擎、SQLite、Docker 与原生 systemd 部署。

## 开发前检查

1. 读取 [实际代码契约](contracts.md)。
2. 读取当前任务的需求、设计和实施计划。
3. 改动前搜索当前实现，不把历史模板作为已经存在的项目约定。

## 质量检查

按 contracts.md 的验证命令与断言执行，跨层修改同时检查另一层契约。

所有内部文档、注释和交互使用中文；默认英文 README、GitHub Actions 的名称和工作流可见提示为用户明确要求的英文例外。

同目录其他指南仍为初始化模板，尚未形成额外有效约束。
